# M2 结果：项目层（2026-11-19）

## 做了什么

### 连接器

- 新增 `src/connector/claude-projects.ts`，项目存在连接器数据目录的 `claude-projects.json` 里，格式和设计一致：`{projects:[{id,name,folders,instructions,memoryDir,mcpServers,sessionIds,coworkSpaceId?}]}`。
  - 写入时先写临时文件再改名；同一时间的多次修改排队执行，不会互相覆盖。
  - 读取时容错：单个项目格式坏了只跳过那一个，整个文件不是合法 JSON 时报错，并提示去电脑上检查。
  - 一个会话只属于一个项目。
- 在项目里启动会话：
  - `cwd` 用 `folders[0]`，`additionalDirectories` 用其余文件夹。
  - `systemPrompt` 是 `{type:'preset', preset:'claude_code', append}`，`append` 包括项目名、文件夹列表、项目说明，以及记忆目录和其中 `MEMORY.md` 的索引（最多 20 KB）。
  - `mcpServers` 按项目配置传入，每个服务器必须有 `command` 或 `url`。
- 项目里的会话以后续聊（resume）时，会重新带上项目当前的设置，所以改了说明或 MCP，下次启动就生效。
- `claude.list` 先列出已配置的项目（`kind:'project'`），再列出文件夹分组（`kind:'folder'`）。文件夹分组只包含不属于任何项目的会话。删除项目不会删除会话，这些会话会回到各自的文件夹分组。
- 新增三个操作：`claude.project.get`、`claude.project.save`、`claude.project.delete`。保存和删除用操作记录（opId）保证重试不会重复执行，连接器更新期间也会被拦下。
- `claude.read` 现在会返回会话所属的项目 `{id,name}`。

### 手机端

- 侧栏把"项目"和"文件夹"分成两组。主页有"新建项目"，进入项目后有"编辑项目"。
- 项目编辑表单可以填名称、文件夹（每行一个）、项目说明、记忆目录和 MCP（JSON）。可以删除项目，删除前会确认。
- 新聊天可以选项目、选已有文件夹，或者"其他文件夹…"手动输入路径。在项目里点新聊天时会自动选好这个项目。会话顶部显示项目名。

### 顺带修的 M1 问题

刚建好的会话第一次读取时，偶尔会报"这台电脑上找不到这条 Claude Code 会话"：对话记录文件已经生成，但 SDK 还读不到这条会话的信息。现在只要会话由手机控制，就先显示为"还没有消息"，不再报错。已补测试。

## 验证

- `npm run check`：209/209 通过，native 检查也通过。`npm run build` 通过。新增的 `test/claude-projects.test.ts` 覆盖了输入校验、存储读写和容错、启动参数组装、项目/文件夹分组，以及在项目里新建会话和续聊。
- 真实 claude.exe（经过连接器）：在一个有两个文件夹、说明和记忆目录的项目里提问，回答里有正确的项目名、记忆索引里的内容，也读到了第二个文件夹里的文件，并且照项目说明在结尾加了指定的词。
- 手机界面：在本机另起一套中继和连接器（独立的配置、Token 和数据目录），在浏览器里用手机尺寸（375×812）测试。项目和文件夹分组正常；编辑项目后，改动写进了文件；在项目里新建聊天时项目已预选，回复用上了改过的说明；会话顶部显示项目名。还修了新聊天页面长路径撑出边框的问题。
