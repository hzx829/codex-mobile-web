# 团队使用说明

多人共用一个中继时用这份说明。管理员第一次启用团队的步骤在 [DEPLOY.md 的“团队成员（可选）”](../../DEPLOY.md#团队成员可选)，设计和实现细节在 [DESIGN.md](DESIGN.md)。

没有启用团队时，一切照旧：大家用同一个连接 Token，这份说明里的功能都不出现。

## 角色

| 角色 | 能做什么 |
| --- | --- |
| 所有者 | 管理员的全部权限，还能添加、管理其他所有者。团队至少要保留一位所有者 |
| 管理员 | 添加和停用成员、改角色（所有者除外）、设定成员能用哪些电脑、管理电脑 Token；能看全员的用量和操作记录 |
| 成员 | 使用分配给自己的电脑；看自己的设备、用量和操作记录 |

所有人都能看到并操作自己可用电脑上的全部会话。会话上的名字只是标记，不是权限：任务都以电脑上那个系统用户的身份运行。

## 成员：登录和日常使用

### 第一次登录

1. 管理员会发给你一个邀请链接或二维码。用手机或电脑浏览器打开即可登录，不需要密码。
2. 邀请链接 24 小时内有效，只能用一次。过期或已经用过，请找管理员重新生成。
3. 也可以先打开中继地址，把邀请链接粘贴到登录页的输入框里。

登录后，这个浏览器会记住你。清除浏览器数据或在无痕窗口里用，需要重新登录。

### 在另一台设备上登录

在已登录的设备上打开 **选项 → 团队 → 我的 → 添加设备**，会生成一个新的邀请链接和二维码，用另一台设备打开即可。每台设备单独登录，可以单独移除。

### 退出和移除设备

- **选项 → 退出登录**：这台设备立即失效，下次要重新邀请。
- **团队 → 我的**：列出你所有的设备，可以移除不再用的（例如丢失的手机），它会立即掉线。

### 会话列表和消息

- 会话行右侧的圆形首字是创建这个会话的人。在电脑上直接开的会话没有标记。
- **选项 → 只看我的会话**：只显示你创建的会话，再点一次恢复全部。
- Codex 会话右上角的状态卡片显示“由谁创建”和“谁最后发送”。
- 一个会话里有别人发的消息时，每条从手机发出的消息上方会显示发送人，你自己的显示“我”。只有你一个人发过消息的会话不显示名字。在电脑上直接输入的消息没有名字。

### 用量

**团队 → 用量**：按今天、7 天、30 天查看轮次和 token。

- 一轮记在发起这一轮的人名下：排队的消息算排队的人；运行中追加的消息并入当前这一轮。
- 输入 token 含缓存命中，括号里是缓存占比。Antigravity 不提供 token 数，只计轮次。
- 用订阅账号（ChatGPT、Claude）登录的电脑，额度由全员共用，token 数表示各人用掉的比例。
- 可以导出 CSV 自己做表。

### 操作记录

**团队 → 记录**：你在什么时候、在哪台电脑上做了什么（新建会话、发送、停止、回应审批、重命名、归档等）和结果。不记录消息内容。

## 管理员：管理团队

都在 **选项 → 团队** 里。

### 添加成员

1. **成员 → 添加成员**，填名字、选角色。
2. 角色是“成员”时，可以只勾选部分电脑；默认是“全部电脑，包括以后连接的”。
3. 点 **添加并生成邀请**，把链接或二维码发给对方。

### 管理已有成员

- **邀请链接**：给对方重新生成一个（例如换了手机、上一个链接过期）。
- **编辑**：改名字、角色和可用电脑。改动立即生效：收回的电脑会从对方的电脑列表里消失。
- **停用**：对方所有设备立即掉线，记录保留；之后可以 **恢复**。

### 电脑

**电脑** 页列出连接过中继的电脑，显示是否在线、用的是共享 Token 还是专用 Token。

- **生成专用 Token**：只给这一台电脑用的 Token，只显示一次。到那台电脑的“修改连接配置”里把 Token 换成它。生成后，这台电脑不能再用共享 Token 连接；如果它断线重连前还没换上新 Token，就会连不上。
- **更换 Token**：旧的专用 Token 立即失效。
- **撤销**：这台电脑改回用共享 Token。

### 用量和记录

管理员在 **用量** 页可以按成员筛选，表格里有“按成员”一栏，“电脑本机”是没有发起人的轮次。**记录** 页显示所有人的操作。

### 所有者的设备全丢了

在服务器上重新生成邀请链接：

```sh
docker compose -f compose.yaml -f compose.https.yaml exec relay node build/relay.mjs team invite --user <名字> --url https://你的域名
```

`team list` 列出所有成员。直接用 Node 运行的中继，以运行中继的系统用户、用相同的 `BRIDGE_DATA` 运行 `build/relay.mjs team …`，命令见 [DEPLOY.md](../../DEPLOY.md#团队成员可选)。

设备丢了能这样找回，服务器上的团队数据库丢了就找不回来了。管理员要定期备份它，步骤见 [DEPLOY.md 的“备份和恢复”](../../DEPLOY.md#备份和恢复)。

## 常见问题

| 现象 | 原因和处理 |
| --- | --- |
| 登录页提示“登录信息无效或已失效” | 邀请链接过期或已用过、设备被移除、成员被停用，或团队刚启用后旧的共享 Token 不能再登录手机。找管理员要新的邀请链接 |
| 电脑列表里少了某台电脑 | 管理员没有把这台电脑分给你，或那台电脑没在线 |
| 用量页没有数据或比预期少 | 电脑连接器要更新到支持用量的版本，更新前的轮次不会补算。在电脑桌面上直接开始的 Codex 轮次不计入。Claude Code 会话第一次从手机继续时，第一轮只作起点不计 token |
| 消息上没有显示名字 | 会话里只有一个人发过消息、消息是在电脑上直接输入的，或者发送时还没有启用团队 |
| 某台电脑连不上中继了 | 管理员给它生成了专用 Token，但那台电脑还在用共享 Token。到那台电脑的连接配置里换上专用 Token |
