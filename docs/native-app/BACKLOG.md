# 原生 App 待办

网页做不到、留到做原生 App（iOS、Android）时再做的交互。每条写明想要的效果、网页为什么做不到，以及 App 里怎么做。

## 选图时输入框叠在相册上（2026-11-23）

参照豆包：点“添加图片”后，全屏是 App 自己画的相册网格，底部浮着输入卡片。点一张照片，它就以大缩略图出现在卡片里，可以接着打字、直接发送，不用先回到聊天页再找输入框。卡片上还有针对这张图的快捷提问（“这是什么”之类）。

网页做不到：网页只能用 `<input type="file">` 调起系统的照片选择器。那是系统界面，网页不能在上面叠自己的输入框，也读不到相册，没法自己画网格。网页现在的流程是“＋ → 添加图片 → 系统选择器 → 回到输入框”。

App 里：申请相册权限（iOS 的受限访问也可以），自己画最近照片的网格，输入框作为底部浮层和网格同屏。选中的照片走现有的附件流程（压缩、整批 8 MiB 上限），点卡片里的缩略图进入已有的图片编辑（裁剪、标记）。
